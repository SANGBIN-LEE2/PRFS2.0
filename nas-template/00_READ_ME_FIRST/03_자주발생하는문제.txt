================================================================
  자주 발생하는 문제
================================================================

[ 텍스처가 안 나와요 / 회색으로 렌더돼요 ]

  원인 : 텍스처 경로가 내 PC를 가리키고 있음

  확인 : Maya 기준
         Windows > General Editors > File Path Editor

  해결 : 모든 텍스처를 NAS 경로로 바꾸고 씬 다시 저장


[ 렌더 결과에 워터마크가 찍혀요 ]

  원인 : Arnold 라이선스를 못 받음
  해결 : 담당자에게 문의
         (라이선스 서버 PC 가 꺼져 있을 수 있습니다)


[ Completed 라고 뜨는데 결과물이 없어요 ]

  Deadline 은 렌더가 실패해도 Completed 로 표시할 때가
  있습니다. 아래 두 가지를 보면 실제로 렌더됐는지 알 수
  있습니다.

  확인 1 : Task Time
           몇 초 만에 끝났으면 렌더를 안 한 것입니다

  확인 2 : Task 우클릭 > View Task Report 에서
           "100% done" 또는 "writing file" 이 있는지

  둘 다 없으면 렌더가 중단된 것이니 담당자에게
  Task Report 를 그대로 전달해주세요.


[ Job이 Queued에서 안 넘어가요 ]

  확인 1 : Deadline Monitor > Workers 에 Online 인 PC가 있는지
  확인 2 : 내가 예약한 그룹을 다른 사람이 쓰고 있는지
  확인 3 : 제출할 때 Group 이름을 맞게 넣었는지


[ 일부 프레임만 렌더됐어요 ]

  먼저 Task Report 를 확인하세요.
  (해당 Task 우클릭 > View Task Report)

  [gpu] no GPU matching requirements found  이 있으면
    원인 : 그 PC 의 그래픽카드 메모리가 부족했습니다
    해결 : Render Settings > Arnold Renderer > System
           > Render Device 를 CPU 로 바꾸고 재제출

  그 외
    해결 : Job 우클릭 > Resume Failed Tasks
           실패한 프레임만 다시 돌아갑니다


[ 받은 파일이 회색으로만 렌더돼요 ]

  원인 : 씬 파일만 받아서 텍스처와 레퍼런스가 빠짐
  해결 : 보낸 사람에게 마야 File > Archive Scene 으로
         다시 받으세요 (참조 파일이 전부 같이 묶입니다)


[ 캐시가 안 읽혀요 ]

  원인 : 캐시 파일이 내 PC에 있거나 상대경로로 지정됨
  해결 : cache 폴더로 옮기고 씬에서 경로 다시 지정


[ 씬을 못 찾는대요 ]

  원인 : 파일 이름이나 폴더에 한글/공백이 있음
  해결 : 영문+숫자로 바꾸고 다시 업로드


[ 렌더가 1분도 안 돼서 끝났어요 ]

  거의 실패입니다.
  Deadline Monitor > Job 선택 > Task > Log 에서
  오류 메시지를 확인하세요.


================================================================
  문제의 90%는 아래 3가지입니다

    1. Worker PC 꺼짐
    2. NAS 연결 끊김
    3. 라이선스 문제

  이 셋을 먼저 확인하세요.
