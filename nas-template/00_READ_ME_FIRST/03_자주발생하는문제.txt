================================================================
  자주 발생하는 문제
================================================================

  최종 수정 : 2026-10-22

  * 추측하지 마시고 로그부터 보세요. 원인이 대부분 거기 있습니다.

    Deadline Monitor > 내 Job 클릭
    > 아래 Task 목록에서 실패한 Task 우클릭 > View Task Report


[ 결과물이 회색으로 나온다 / 텍스처가 안 나온다 ]

  원인 : 텍스처 경로가 내 PC를 가리키고 있음
  확인 : Maya > Windows > General Editors > File Path Editor
  해결 : 빨간 줄을 전부 선택 > Repath Files > NAS 폴더 지정
         빨간 줄이 0개가 될 때까지 반복

  * 이 경우 렌더가 중단되지 않습니다.
    결과물을 봐야만 알 수 있으니 3프레임 테스트를 꼭 하세요.


[ 캐릭터가 통째로 안 보인다 ]

  원인 : 레퍼런스가 걸려 있음
  해결 : File > Reference Editor
         > Reference > Import Objects from Reference

  * 남에게 파일을 받을 때는 File > Archive Scene 으로 받으세요.
    씬 파일만 받으면 텍스처와 레퍼런스가 전부 빠집니다.


[ Completed 인데 결과물이 없다 ]

  원인 : 출력 경로가 다른 곳을 가리키고 있음
  확인 : 로그에서 writing file 로 시작하는 줄을 보세요.
         실제 저장 위치가 그대로 적혀 있습니다.
  해결 : 거기 있으면 가져가시면 됩니다.


[ 폴더 안에 폴더가 계속 생긴다 / 경로가 두 번 나온다 ]

  이렇게 보입니다.

    writing file
    //...C393169/output/20261103_final/beauty///223.194.101.83/...

  원인 : 제출 창의 Output Path 와
         Render Settings 의 File name prefix 에
         둘 다 전체 경로가 들어가 있음

  해결 : File name prefix 에는 파일 이름만 넣으세요. (예: shot01)
         폴더는 제출 창의 Output Path 가 정합니다.


[ 장수가 모자란다 / 몇 장만 빠진다 ]

  원인 : Render Device 가 GPU 로 되어 있음
  해결 : Render Settings > Arnold Renderer > System
         > Render Device 를 CPU 로

  * Arnold는 그래픽카드 메모리가 부족하면
    CPU로 넘어가지 않고 그냥 중단합니다.
    공용 PC라 GPU 상태가 제각각이어서 일부만 조용히 실패합니다.


[ 몇 초 만에 끝난다 / 씬을 못 찾는다 ]

  원인 : 경로에 한글이나 공백이 있음
  해결 : 폴더와 파일 이름을 영문 소문자, 숫자, 밑줄로 바꾸세요.
         프로젝트 안쪽까지 전부 확인해야 합니다.


[ 카메라가 이상한 각도로 렌더된다 ]

  원인 : 제출할 때 Camera 를 비워둠
  해결 : 제출 창의 Camera 에서 렌더할 카메라를 고르세요.
         비우면 persp 뷰로 렌더됩니다.


[ 워터마크가 찍힌다 / Queued 에서 안 넘어간다 ]

  라이선스 또는 장비 문제일 수 있습니다.
  학생이 설정을 고치지 마시고 담당자에게 알려주세요.
  어느 번호 PC인지 같이 알려주시면 빠릅니다.


[ 담당자에게 연락할 때 ]

  아래 네 가지를 같이 보내주세요.

    1. Job 이름 / 학번
    2. Task Report 로그 전체 (복사 붙여넣기)
    3. 쓰신 프로그램과 버전
    4. NAS 작업 폴더 경로
