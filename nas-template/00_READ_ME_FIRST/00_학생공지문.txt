       M211 렌더팜 사용 안내 (영상애니메이션학부)

렌더팜 이용을 원하는 학생은 아래 내용을 확인해주세요.


[ 1. 렌더팜이란 ]

  실습실 PC 여러 대가 렌더링을 나눠서 처리하는 시스템입니다.
  내 PC 한 대로 며칠 걸리는 작업을 여러 대가 동시에 처리합니다.


[ 2. 지원 소프트웨어 ]

  Maya 2026   (Arnold)
  Blender     (Cycles / Eevee)

  * Maya 는 2026 버전을 사용하세요.
    렌더팜의 Arnold 라이선스가 2026 전용입니다.
    하위 버전 씬도 렌더는 되지만 2026에서 작업하는 것이
    가장 안전합니다.


[ 3. 이용 절차 ]

  (1) 사용 신청
      담당자에게 학번/이름을 전달하여 계정 등록

  (2) 예약
      예약 시트에서 원하는 시간 블록을 예약
        - 1일 최대 2블록
        - 1주 최대 6블록

  (3) 파일 업로드
      아래 경로에 본인 학번 폴더를 만들고 업로드

        \\223.194.101.83\2026_renderfarm\input\

  (4) 렌더 제출
      실습실 PC의 Deadline Monitor 에서 제출

      * 제출 전 Render Device 를 CPU 로 바꾸세요
        (Arnold Renderer > System > Render Device)

  (5) 결과물 수령
      아래 경로에서 결과물 수령

        \\223.194.101.83\2026_renderfarm\output\


[ 4. 내 폴더 만들기 ]

  방법 A - 자동 (권장)

    \\223.194.101.83\2026_renderfarm\_admin\scripts\
    02_학생용_내폴더만들기.bat  실행

    학번과 작업명을 입력하면 자동으로 만들어집니다

  방법 B - 수동

    input 폴더의  00_TEMPLATE  폴더를 복사한 뒤
    폴더명을 본인 학번으로 변경


[ 5. 폴더 구조 ]

  input\C393169\20261020_test\
                   scenes\        씬 파일
                   textures\      텍스처
                   cache\         캐시
                   JOB_INFO.txt   작업 정보

  output\C393169\20261020_test\  결과물


[ 6. 반드시 지켜야 할 것 ]

  (1) 모든 파일은 NAS에 있어야 합니다

      내 PC의 C:\ D:\ 바탕화면에 파일이 있으면
      Worker PC가 그 파일을 못 읽어서 렌더가 실패합니다

  (2) 경로에 한글과 공백을 쓰지 마세요

      나쁨 : 10월20일 최종본\장면 1.mb
      좋음 : 20261020_final\scene_01.mb

  (3) 출력 경로는 UNC 경로로 지정하세요

      나쁨 : Z:\output\C393169\...
      좋음 : \\223.194.101.83\2026_renderfarm\output\C393169\...

      Z: 드라이브는 PC마다 다르게 잡힐 수 있습니다

  (4) 텍스처 경로를 NAS로 다시 지정하세요

      Maya : Windows > General Editors > File Path Editor

      경로가 내 PC를 가리키면 렌더가 회색으로 나옵니다

  (5) 먼저 작은 테스트부터 하세요

      프레임 1-3, 저해상도로 먼저 확인한 뒤
      본 작업을 제출하세요

  (6) 다른 사람 폴더를 건드리지 마세요


[ 7. 작업 종료 후 ]

  - 결과물을 받아간 뒤 output 폴더를 정리해주세요
  - cache 폴더를 비워주세요
  - 용량이 차면 다른 사람이 렌더를 못 합니다
