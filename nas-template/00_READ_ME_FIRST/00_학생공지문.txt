[ 1. 렌더팜이란 ]

  실습실 PC 여러 대가 렌더링을 나눠서 처리하는 시스템입니다.
  내 PC로 밤새 돌릴 작업을 몇 시간 만에 끝낼 수 있습니다.

  내 작업 파일 -> NAS 업로드 -> Deadline 제출
              -> PC 여러 대가 나눠서 렌더 -> NAS에서 수령


[ 2. 지원 소프트웨어 ]

  Maya + Arnold   사용 가능. 전 구간 검증 완료

    * 마야 버전은 신경 쓰지 않으셔도 됩니다.
      어떤 버전으로 만든 씬이든 렌더팜이 Maya 2026으로 렌더합니다.
      2025에서 작업하셔도 되고, 구버전 파일 경고도 무시하셔도 됩니다.

  Blender         준비 중. 파일 준비까지만 해두세요

    * 실습실 PC의 블렌더 버전을 통일하는 중입니다.
      제출은 졸업준비위원회 공지 후에 해주세요.
    * 블렌더는 상위 호환이 안 됩니다.
      높은 버전으로 저장하면 렌더팜이 열지 못합니다.


[ 3. 이용 절차 ]

  (1) 신청
      위 [0]의 구글폼을 작성합니다.
      학번(팀은 팀장 1명), 이름, 프로젝트명, 영상 분량,
      연락처, 사용 프로그램, 예상 프레임 수를 적습니다.

      * 영상 분량에 따라 주당 쓸 수 있는 시간이 달라집니다.
          3분 이하   주 32시간
          3 ~ 6분    주 64시간
          6분 초과   주 96시간

  (2) 예약
      신청이 등록되면 예약 시트를 공유해드립니다.
      본인이 렌더할 주의 탭에서 시간대와 레인을 고르고,
      드롭다운에서 본인 학번을 선택합니다.

      * 예약 취소는 그 칸을 클릭하고 Delete 입니다.
      * 남의 예약 칸은 건드리지 마세요.
        누가 언제 무엇을 바꿨는지 전부 기록에 남습니다.

  (3) 파일 준비
      레퍼런스 Import / 모든 파일을 NAS 경로로 /
      Render Device를 CPU로 / 출력 경로 지정

  (4) 업로드
      본인 학번 폴더 안의 input 폴더에 올립니다.

  (5) 제출
      예약한 시간에 실습실 PC에서 Deadline에 제출합니다.
      Pool은 예약한 레인과 똑같이 고릅니다.

  (6) 수령
      output 폴더에서 받고, 받은 뒤에는 폴더를 비워주세요.

[ 5. 올리기 전에 꼭 확인하세요 ]

  1. 집에서 1프레임이 제대로 렌더되는 씬만 올려주세요.
     집에서 안 되는 씬은 렌더팜에서도 안 됩니다.

  2. 프로젝트 폴더를 통째로 올려주세요.
     씬 파일만 올리면 텍스처가 전부 빠져서 회색으로 나옵니다.

  3. 폴더와 파일 이름에 한글, 공백, 점(.) 을 쓰지 마세요.

  4. 전체를 돌리기 전에 3프레임만 먼저 돌려서 확인하세요.
     경로가 하나 틀리면 300프레임이 전부 실패합니다.
