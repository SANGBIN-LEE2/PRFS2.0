[ 경로 세 줄 ]

  올리는 곳
    \\223.194.101.83\2026_renderfarm\내학번\input\날짜_작업명\

  받는 곳
    \\223.194.101.83\2026_renderfarm\내학번\output\날짜_작업명\

  안내문
    \\223.194.101.83\2026_renderfarm\00_READ_ME_FIRST

  * 본인 학번 폴더는 이미 만들어져 있습니다.
    그 안에 날짜_작업명 폴더만 직접 만드시면 됩니다.
    예) 20261103_final
  * output 쪽에도 같은 이름으로 하나 만들어주세요.
    폴더가 없으면 렌더가 결과물을 쓸 곳이 없습니다.


[ 예약하기 ]

  예약 시트는 주 단위로 탭이 나뉘어 있습니다.

    명단           내 학번과 라이선스 (보기 전용)
    10.26~11.01    주차별 예약표
    11.02~11.08
       ...
    사용 규칙       타임블럭과 위반 규정

  본인이 렌더할 주의 탭에서
  날짜 x 시간대 x 레인이 만나는 빈 칸을 클릭하고
  드롭다운에서 본인 학번을 고릅니다.

  * 고른 레인(pool_a ~ pool_d)을 꼭 기억하세요.
    제출할 때 Pool 칸에 같은 값을 넣어야 합니다.
  * 회색 칸은 수업 시간이라 예약할 수 없습니다.
  * 취소는 그 칸을 클릭하고 Delete.


[ 마야 설정 네 가지 ]

  (1) 레퍼런스를 Import 로 바꾸기
      File > Reference Editor
      > 레퍼런스 선택 > Reference > Import Objects from Reference

  (2) 모든 파일을 NAS 경로로
      Windows > General Editors > File Path Editor
      빨간 줄이 0개가 될 때까지 Repath Files

  (3) Render Device 를 CPU 로
      Render Settings > Arnold Renderer > System > Render Device

  (4) 출력 경로 지정
      아래 [ 출력 경로 ] 항목을 보세요

  마지막에 반드시  Ctrl + S
  렌더팜은 저장된 내용만 읽습니다.


[ 출력 경로 ]  * 가장 많이 틀리는 부분입니다

  절대경로는 한 군데에만 넣으세요.

    제출 창의  Output Path          폴더 경로를 넣습니다
    Render Settings 의
    File name prefix                파일 이름만 넣습니다 (예: shot01)

  둘 다 전체 경로를 넣으면 두 경로가 이어 붙어서
  폴더 안에 폴더가 계속 생깁니다.

  제대로 들어갔으면 Render Settings 의 File name: 줄이
  경로 없이 파일 이름만 보입니다.

    File name: shot01.0001.png


[ 제출할 때 ]

  마야 상단 셸프의 Deadline 탭 > 초록색 아이콘
  또는  Deadline Monitor > Submit > 3D > Maya

  * 실습실 PC마다 셸프가 있는 PC와 없는 PC가 섞여 있습니다.
    셸프에 Deadline 탭이 없으면 Monitor 쪽으로 하세요.

  입력할 항목은 다섯 개뿐입니다.

    Job Name       알아보기 쉬운 이름
    Pool           예약한 레인 (pool_a ~ pool_d)
    Frame List     처음엔 씬의 실제 범위에서 3장
    Camera         렌더할 카메라 (비우면 persp로 렌더됩니다)
    Output Path    NAS output 폴더

  나머지는 기본값 그대로 두세요. Group 은 none 입니다.


[ 프레임 범위 ]

  씬마다 다릅니다. 만든 사람이 정한 값이라 열어봐야 압니다.

    Render Settings > Common > Frame Range
    또는 마야 아래쪽 타임라인의 시작과 끝 숫자

  Frame List 쓰는 법

    1001-1041        1001부터 1041까지 전부
    1001-1041x5      5프레임 간격 - 1001, 1006, 1011 ...
    1001,1006,1011   적은 것만

  * 마야 Render Settings 의 By frame 은 Deadline이 무시합니다.
    간격은 Frame List 에 x 로 직접 써야 합니다.
  * 1001부터 시작하는 씬에 1-3 을 넣으면
    애니메이션이 시작되기도 전인 구간이 렌더됩니다.


[ 꼭 기억할 세 가지 ]

  1. 내 PC에만 있는 파일은 렌더팜이 못 읽습니다.
     씬, 텍스처, 캐시가 전부 NAS에 있어야 합니다.

  2. 경로에 한글, 공백, 점(.) 을 쓰지 마세요.
     하나라도 섞이면 파일을 못 찾습니다.

  3. 전체를 돌리기 전에 3프레임만 먼저 돌리세요.
     경로가 하나 틀리면 300프레임이 전부 실패합니다.

  * 결과물은 파일 개수만 세지 말고 반드시 열어보세요.
    텍스처가 빠져서 회색으로 나와도 개수는 맞게 나옵니다.


[ 끝난 뒤 ]

  결과물을 본인 저장장치로 옮기고
  NAS output 폴더를 비워주세요.
  EXR 시퀀스는 용량이 커서, 안 치우면 다른 팀이 렌더를 못 합니다.
