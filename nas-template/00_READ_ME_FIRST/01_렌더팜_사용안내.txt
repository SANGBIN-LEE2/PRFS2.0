================================================================
  M211 렌더팜 사용 안내
================================================================

처음 쓰는 사람은 이 파일부터 읽으세요.


[ 1. 렌더팜이 뭔가요 ]

실습실 PC 여러 대가 렌더링을 나눠서 처리합니다.
내 PC 한 대로 밤새 돌릴 작업을 여러 대가 동시에 처리합니다.


[ 2. 전체 흐름 ]

  (1) 예약          예약 시트에서 시간 블록 예약
        |
  (2) 업로드        내 작업 파일을 NAS input 폴더에 올림
        |
  (3) 제출          실습실 PC에서 Deadline으로 렌더 제출
        |
  (4) 렌더          Worker PC들이 나눠서 렌더링
        |
  (5) 수령          NAS output 폴더에서 결과물 가져감


[ 2-1. 사용할 소프트웨어 ]

  Maya 는 반드시 2026 버전으로 작업하세요.
  이 렌더팜의 Arnold 라이선스는 2026 전용입니다.

  구버전(2023~2025) 씬을 올려도 Worker 가 2026 으로 열어서
  렌더하므로 결과물은 나옵니다. 다만 버전 차이로 생기는
  오류를 피하려면 처음부터 2026 에서 작업하세요.

  구버전 씬을 2026 에서 열면
  "이전 버전에서 만들어진 파일" 경고가 뜹니다. 정상입니다.


[ 2-2. 제출 전 반드시 바꿀 것 ]

  마야  Render Settings
        > Arnold Renderer > System > Render Device = CPU

  GPU 로 두면, 그래픽카드가 바쁜 PC 에 배정된 프레임만
  실패합니다. 전체가 아니라 일부만 빠지기 때문에
  모르고 넘어가기 쉽습니다.

  실습실 PC 는 20 코어 CPU 와 64GB 메모리를 갖고 있어
  CPU 렌더로도 충분합니다.


[ 2-3. 다른 사람에게 파일을 받을 때 ]

  씬 파일(.mb) 하나만 받으면 텍스처와 레퍼런스가
  전부 빠집니다. 씬에는 파일이 아니라 "그 파일이 있던
  경로" 만 적혀 있기 때문입니다.

  더 나쁜 것은 이 상태로도 렌더가 그냥 돈다는 점입니다.
  텍스처 없이 회색으로, 캐릭터가 빠진 채로 완료됩니다.

  보내는 사람에게 이렇게 요청하세요.

      마야에서  File > Archive Scene

  씬이 참조하는 텍스처 · 레퍼런스 · 캐시가 전부
  zip 으로 묶입니다.

  받은 뒤에는 씬을 열고
      Windows > General Editors > File Path Editor
  에서 빨간 줄(못 찾는 파일)이 없는지 확인하세요.


[ 3. 내 폴더 주소 ]

  업로드할 곳
  \\223.194.101.83\2026_renderfarm\input\내학번\

  결과물 받을 곳
  \\223.194.101.83\2026_renderfarm\output\내학번\


[ 4. 가장 먼저 할 일 ]

  input 폴더 안의  00_TEMPLATE  폴더를 통째로 복사해서
  본인 학번 이름으로 바꾸세요.

  예)  00_TEMPLATE  →  C393169


[ 5. 절대 지켜야 할 것 ]

  - 모든 파일은 NAS에 있어야 합니다
  - 내 PC의 C:\ D:\ 바탕화면에 파일이 있으면 렌더가 실패합니다
  - 폴더/파일 이름에 한글, 공백, 특수문자를 쓰지 마세요
  - 다른 사람 폴더를 건드리지 마세요
