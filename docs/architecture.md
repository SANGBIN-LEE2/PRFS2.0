## 렌더링 Job 흐름

```
학생이 C4D에서 "Submit to Deadline" 클릭
              ↓
Job이 Deadline Repository에 등록 (상태: Queued)
              ↓
Deadline이 여유 Worker에게 작업 배분
              ↓
Worker가 스토리지에서 씬 파일 읽어 렌더링 (상태: Rendering)
              ↓
결과물을 스토리지 output 폴더에 저장 (상태: Completed)
```
