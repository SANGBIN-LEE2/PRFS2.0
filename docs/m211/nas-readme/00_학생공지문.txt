================================================================
       M211 렌더팜 이용 안내 (영상애니메이션학부)
================================================================

렌더팜을 이용하려는 학생은 아래 내용을 확인해주세요.

  최종 수정 : 2026-10-19


[ 1. 렌더팜이란 ]

  실습실 PC 여러 대가 렌더링을 나눠서 처리하는 시스템입니다.
  내 PC로 밤새 돌릴 작업을 몇 시간 만에 끝낼 수 있습니다.

  내 작업 파일 -> NAS 업로드 -> Deadline 제출
              -> PC 여러 대가 나눠서 렌더 -> NAS에서 수령


[ 2. 지원 소프트웨어 ]

  Maya + Arnold   사용 가능. 전 구간 검증 완료

    * 마야 버전은 신경 쓰지 않으셔도 됩니다.
      어떤 버전으로 만든 씬이든 렌더팜이 Maya 2026으로 렌더합니다.
      2025에서 작업하셔도 되고, 구버전 파일 경고도 무시하셔도 됩니다.

  Blender         준비 중. 파일 준비까지만 해두세요

    * 실습실 PC의 블렌더 버전을 통일하는 중입니다.
      제출은 졸업준비위원회 공지 후에 해주세요.


[ 3. 이용 절차 ]

  (1) 신청
      졸업준비위원회에 아래 네 가지를 제출합니다.

        팀 프로젝트명
        팀장 학번
        이메일
        프로젝트 분량 (분)

      * 분량에 따라 주당 쓸 수 있는 시간이 달라집니다.

  (2) 예약
      졸준위가 공유하는 구글 시트에서
      시간 블록과 레인(A~D)을 고르고 본인 학번을 적습니다.

  (3) 파일 준비
      레퍼런스 Import / 모든 파일을 NAS 경로로 /
      Render Device를 CPU로 / 출력 경로 지정

  (4) 업로드
      본인 학번 폴더 안의 input 폴더에 올립니다.

  (5) 제출
      예약한 시간에 실습실 PC에서 Deadline에 제출합니다.
      Pool은 예약한 레인과 똑같이 고릅니다.

  (6) 수령
      output 폴더에서 받고, 받은 뒤에는 폴더를 비워주세요.


[ 4. 자세한 사용법 ]

  이 폴더의  04_렌더팜_사용법.pdf  를 보세요.
  화면 사진과 함께 단계별로 설명되어 있습니다.

  온라인 가이드(노션)는 졸업준비위원회 공지를 참고하세요.
  내용이 바뀌면 온라인 쪽이 먼저 갱신됩니다.


[ 5. 문의 ]

  예약 / 타임블럭 배정      졸업준비위원회
  렌더 실패 / 장비 문제     이상빈 (C393169)

  * 문제가 생기면 Deadline Monitor에서
    Task Report 로그를 통째로 복사해서 보내주세요.
