[ 올릴 때 ]

  씬 파일만 올리면 안 됩니다.
  쓰시던 프로젝트 폴더를 통째로 복사해 넣으세요.

    MyProject\
      +- scenes\
      +- sourceimages\
      +- cache\
      +- workspace.mel

  씬에는 텍스처가 들어있지 않고 "텍스처가 어디 있다"는
  경로만 적혀 있습니다. 씬만 올리면 회색으로 렌더됩니다.


[ 이름 규칙 ]

  써도 되는 것    영문 소문자, 숫자, 밑줄( _ )
  쓰면 안 되는 것  한글, 공백, 점( . ), 특수문자

  * 맨 위 폴더만 바꿔도 안쪽에 공백이 있으면 똑같이 실패합니다.
    프로젝트 안쪽 폴더와 파일 이름까지 확인하세요.

  공백이 있으면 경로가 거기서 끊깁니다.

    .../scenes/s03 c220/ Lighting/shot_v003.mb    (X)
    .../scenes/s03_c220/Lighting/shot_v003.mb     (O)

  점이 있으면 확장자로 착각해서 그 지점을 끝으로 읽습니다.

    .../scenes.mb/s03_c220/shot_v003.mb           (X)
    .../scenes/s03_c220/shot_v003.mb              (O)


[ 결과물 폴더가 여러 개로 나뉘는 경우 ]

  씬에 AOV(렌더 패스)를 켜두셨으면
  패스 이름으로 폴더가 하나씩 생깁니다. 정상입니다.

    20261103_final\
      +- beauty\         <- 최종 이미지
      +- background\
      +- ID\

  beauty 폴더가 최종 이미지입니다.
  AOV를 끄실 필요는 없습니다. 합성에 쓰시면 됩니다.


[ 정리 ]

  결과물을 받으신 뒤에는 input 과 output 양쪽을 비워주세요.
  공용 저장소라 용량이 차면 다른 팀이 렌더를 못 합니다.
