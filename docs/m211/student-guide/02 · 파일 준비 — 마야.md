# 🅰 02 · 파일 준비 — 마야

> **렌더 실패 원인의 90%가 이 단계에 있습니다.** 천천히 하세요.

핵심은 하나입니다. **내 PC에만 있는 파일은 Worker가 못 읽습니다.** 씬·텍스처·캐시가 전부 NAS에 있어야 합니다.

---

## 먼저 — 마야 버전

**2026으로 작업하세요.** 렌더팜의 Arnold 라이선스가 2026 전용입니다.

하위 버전에서 만든 씬도 렌더는 됩니다. 구버전 씬을 2026에서 열 때 뜨는 "이전 버전 파일" 경고는 무시해도 됩니다.

---

## 2-1. 레퍼런스를 Import로 바꾸기

씬에 레퍼런스(Reference)가 걸려 있으면 **렌더할 때 깨집니다.** 미리 Import 상태로 바꾸세요.

```
File → Reference Editor
→ 레퍼런스 선택 → Reference → Import Objects from Reference
```

![Reference Editor](img/02_refeditor.png)

**①** 걸려 있는 레퍼런스입니다. 선택한 뒤 `Reference → Import Objects from Reference` 를 누르세요.

> 원본 파일이 없으면 그 메뉴가 비활성화됩니다. 그때는 파일을 보낸 사람에게 원본을 먼저 받아야 합니다.

레퍼런스가 없으면 이 단계는 건너뜁니다.

---

## 2-2. 텍스처 경로를 NAS로 바꾸기

```
Windows → General Editors → File Path Editor
```

![File Path Editor](img/03_filepath_red.png)

**①** `0 Resolved, 79 Unresolved` — 79개를 전부 못 찾고 있다는 뜻입니다. 왼쪽 빨간 X가 그 표시입니다.
경로가 `D:\Projects\...` 처럼 **다른 사람 PC**를 가리키고 있습니다.

**②** 빨간 줄을 전부 선택한 뒤 `Repath Files` 를 누릅니다.

**빨간 줄이 하나라도 있으면 안 됩니다.**

![Repath](img/04_repath.png)

**①** `New Path` 에 NAS의 `textures` 폴더를 지정합니다.
**②** `Repath` 클릭.

> 제대로 됐다면 빨간 X가 사라지고 `Resolved` 숫자가 올라갑니다.

---

## 2-3. 출력 경로 지정

```
Render Settings → Common 탭
```

| 항목 | 값 |
| --- | --- |
| **File name prefix** | `//223.194.101.83/2026_renderfarm/output/내학번/작업폴더/파일이름` |
| Image format | `exr` 또는 `png` |
| Frame/Animation ext | `name.#.ext` |
| Frame Range | 렌더할 범위 |

![Render Settings](img/05_maya_submit.png)

**①** `File name:` 줄에 NAS 출력 경로가 들어가 있는지 확인합니다. 이 줄이 실제로 저장될 위치입니다.

> **마야는 슬래시 방향이 `/` 입니다.** `Z:\` 같은 드라이브 문자는 쓰면 안 됩니다 — Worker PC에는 그 드라이브가 없습니다.

---

## 2-4. 렌더 디바이스를 CPU로

```
Render Settings → Arnold Renderer 탭 → System → Render Device → CPU
```

![Render Device](img/06_arnold_device.png)

**①** `Device Selection → Render Device` 를 `CPU` 로 둡니다.

> GPU로 두면 **그래픽카드가 바쁜 PC에 배정된 프레임만 조용히 실패합니다.** 전체가 아니라 일부만 빠지기 때문에 모르고 넘어가기 쉽습니다. 240프레임 중 몇 장이 비어 있는 걸 나중에 발견하면 그만큼 시간을 날립니다.

---

## 2-5. 저장

**`Ctrl + S`**

저장하지 않으면 위 설정이 씬에 들어가지 않습니다. Worker는 **저장된 내용만** 읽습니다.

---

## 💡 파일을 남에게 받았다면

다른 사람에게 씬을 받을 때는 **씬 파일만 받으면 안 됩니다.** 씬에는 파일이 아니라 **경로만** 기록되어 있어서, 텍스처와 레퍼런스가 전부 빠집니다.

보내는 쪽이 이렇게 하면 됩니다.

```
File → Archive Scene
```

씬이 참조하는 텍스처·레퍼런스·캐시가 전부 zip으로 묶입니다.

받은 뒤에는 반드시 `File Path Editor` 로 빨간 줄이 없는지 확인하세요.

---

## ✅ 컬러 매니지먼트는 신경 쓰지 않아도 됩니다

마야 컬러 매니지먼트(OCIO) 때문에 렌더가 즉시 중단되는 문제가 있었지만, **우리 렌더팜은 서버에서 처리하도록 수정했습니다.**

학생이 스크립트를 돌리거나 설정을 바꿀 필요가 없습니다. 컬러 매니지먼트는 **기본값 그대로 두세요.**
