# 🚀 05 · 렌더 제출하기

예약한 시간이 되면 실습실 PC에서 제출합니다.

---

## ⚠️ 먼저 — 3프레임부터

**반드시 3프레임만 먼저 돌리세요.**

경로가 하나라도 틀리면 전체 프레임이 다 실패합니다. 3장으로 확인하고 늘리면 시간을 아낄 수 있습니다.

```
1차   Frame List  1-3     →  결과물 3장 확인  →  OK
2차   Frame List  전체
```

---

## 🅰 마야

### 5-1. NAS에서 씬 열기

`File → Open Scene` → 파일 이름 칸에 경로를 **직접 입력**:

```
\\223.194.101.83\2026_renderfarm\input\내학번\작업폴더\scenes\
```

> 마야 탐색기에는 네트워크 위치가 기본으로 안 뜹니다. 경로를 쳐서 들어가야 합니다.

### 5-2. 프로젝트 지정

```
File → Set Project → \\223.194.101.83\2026_renderfarm\input\내학번\작업폴더
```

`scenes` 가 아니라 **그 상위 폴더**입니다.

### 5-3. 제출 창 열기

```
상단 메뉴 Deadline → Submit Maya To Deadline
```

![Deadline Submitter](img/05_maya_submit.png)

**②** `Group` — 예약한 것과 똑같이 고릅니다.
**③** `Frame List` — 처음엔 `1-3`.
**④** `Frames Per Task` — `1`.

### 5-4. 입력할 항목

| 항목 | 값 |
| --- | --- |
| **Job Name** | 알아보기 쉬운 이름 (예: `C393169_final`) |
| **Camera** | **렌더할 카메라를 직접 고르세요** |
| **Frame List** | 렌더할 범위. **처음엔 `1-3`** |
| **Frames Per Task** | `1` |
| **Concurrent Tasks** | **`1`** (아래 설명) |
| **Pool / Group** | 예약한 그룹과 **똑같이** |
| Priority | 기본값 그대로 |

> **Camera를 빼먹지 마세요.** 기본 카메라(persp)로 렌더되면 전부 다시 돌려야 합니다.

> `Frames Per Task` 를 `1` 로 두면 프레임 하나씩 여러 PC에 흩어집니다. 이게 가장 빠릅니다.
> 시뮬레이션처럼 **순서대로 돌아야 하는 작업**은 예외입니다. 그때는 졸준위에 문의하세요.

### Concurrent Tasks — 처음엔 1로 두세요

한 PC의 CPU를 **몇 개의 작업으로 쪼갤지** 정하는 값입니다.

| 설정 | 결과 |
| --- | --- |
| `1` | 프레임당 빠름, 전체도 빠름 |
| `4` | 동시에 4프레임을 잡지만 **각각 느려지고 총 시간도 늘어남** |

숫자를 올리면 더 빨라질 것 같지만 **반대입니다.** 같은 CPU를 나눠 쓰는 것뿐이고 메모리도 4배로 듭니다. 특별한 이유가 없으면 `1` 로 두세요.

### 5-5. Submit

**`Submit Job`** 버튼을 누릅니다.

## 🅱 블렌더

블렌더는 **Deadline Monitor에서 바로 제출**할 수 있습니다. 블렌더를 켜지 않아도 됩니다.

```
바탕화면 Deadline Monitor 실행
→ 상단 메뉴 Submit → 3D → Blender
```

![Submit 메뉴](img/13_submit_menu.png)

![Blender 제출 창](img/14_blender_submit.png)

**①** `Blender File` — NAS의 `.blend` 파일
**②** `Output File` — NAS 출력 경로 (`####` 포함, `\\` 로 시작)
**③** `Frame List` — 처음엔 `1-3`
**④** `Submit Blender Scene File With The Job` — **절대 체크하지 마세요.** 씬 파일을 Repository에 통째로 복사해 올려서 서버 용량을 잡아먹습니다.

| 항목 | 값 |
| --- | --- |
| **Blender File** | NAS의 `.blend` 파일 선택 |
| **Output File** | `\\223.194.101.83\...\이름_####` |
| **Frame List** | **처음엔 `1-3`** |
| **Frames Per Task** | `1` |
| **Pool / Group** | 예약 시트에 적힌 것과 똑같이 |

## 제출하고 나면

실습실을 떠나도 됩니다. 렌더는 Worker PC들이 알아서 돌립니다.

다만 **실습실 PC를 끄지 마세요.** 끄면 그 PC가 맡은 프레임이 멈춥니다. 실습실에 꺼진 PC가 보이면 켜주세요 — 켜져 있는 PC가 많을수록 모두의 렌더가 빨라집니다.

> **Output 경로를 메모장에 복사해두세요.** 나중에 결과물을 찾을 때 헤매지 않습니다.
