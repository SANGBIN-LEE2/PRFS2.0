## 4-1. 내 폴더 만들기

탐색기 주소창에 붙여넣기:

```
\\223.194.101.83\2026_renderfarm\input\
```

![input 폴더](img/10_input.png)

**①** `00_TEMPLATE` 을 복사해서 본인 학번으로 이름을 바꾸세요.

그 안에 다시 `날짜_작업명` 폴더를 만듭니다.

```
input\
  └ C393169\              ← 내 학번
      └ 20261103_final\   ← 날짜_작업명
          ├ scenes\       ← 씬 파일 (.mb / .blend)
          ├ textures\     ← 텍스처
          ├ cache\        ← 캐시·시뮬레이션
          └ JOB_INFO.txt
```

## 4-2. ⚠️ 씬 파일만 올리면 안 됩니다

**프로젝트 폴더를 통째로** 올리세요. 씬 파일 하나만 올리면 텍스처가 전부 빠져서 회색으로 렌더됩니다.

```
scenes\myshot.mb 만 복사            ❌
프로젝트 폴더 전체를 복사           ✅
```

---

## 4-3. 폴더·파일 이름 규칙

```
형식   날짜_작업이름
예시   20261103_final     20261105_retake
```

| ✅ 써도 되는 것 | ❌ 쓰면 안 되는 것 |
| --- | --- |
| 영문 소문자, 숫자, 밑줄(`_`) | 한글, 공백, 점(`.`), 특수문자 |

### 왜 안 되나요?

Worker PC가 경로를 **문자 그대로** 읽습니다.

**공백이 있으면** — 경로가 거기서 끊깁니다.

```
.../scenes/s03 c220/ Lighting/shot_v003.mb    ❌
.../scenes/s03_c220/Lighting/shot_v003.mb     ✅
```

**점(`.`)이 있으면** — 확장자로 착각해서 그 지점을 경로의 끝으로 읽습니다.

```
.../scenes.mb/s03_c220/Lighting/shot_v003.mb  ❌
.../scenes/s03_c220/Lighting/shot_v003.mb     ✅
```

> 이미 공백이 잔뜩 들어간 프로젝트라면 손으로 고치지 마세요. `07 · 자주 발생하는 에러` 에 일괄 제거 스크립트가 있습니다.

## 4-5. 업로드

작업 파일을 위 폴더에 복사합니다. 이미 올렸던 프로젝트라면 **바뀐 파일만** 덮어쓰면 됩니다.

> 업로드와 씬 세팅은 **실습실 어느 PC에서나** 할 수 있습니다. 제출용 PC는 제출에만 쓰고, 준비 작업은 다른 자리에서 하세요.
