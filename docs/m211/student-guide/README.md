# 🎬 M211 렌더팜 가이드

> **📡 현재 운영 상태 · 2026.10.17**
>
> 🅰 **마야** — 사용 가능. 전 구간 검증 완료 (버전 상관없음)
> 🅱 **블렌더** — 파일 준비까지 진행하세요. 실습실 PC의 블렌더 버전을 통일하는 중이라, **제출은 공지 후에** 해주세요
> 🗓 **예약** — 시트 준비 중. 졸업준비위원회 공지를 기다려주세요
>
> 이 칸은 상황이 바뀔 때마다 갱신됩니다.

실습실 PC 여러 대가 렌더링을 나눠서 처리합니다. 내 PC로 밤새 돌릴 작업을 몇 시간 만에 끝낼 수 있습니다.

```
내 작업 파일  →  NAS 업로드  →  Deadline 제출  →  PC 여러 대가 나눠서 렌더  →  NAS에서 수령
```

## 꼭 기억할 3가지

> **1. 내 PC에만 있는 파일은 Worker가 못 읽습니다.**
> 씬·텍스처·캐시가 전부 NAS에 있어야 합니다. 렌더 실패의 대부분이 이것입니다.

> **2. 경로에 한글·공백·점(`.`)을 쓰지 마세요.**
> Worker가 경로를 문자로 읽습니다. 하나라도 섞이면 파일을 못 찾습니다.

> **3. 전체를 돌리기 전에 3프레임만 먼저 돌리세요.**
> 경로가 하나 틀리면 300프레임이 전부 실패합니다. 3장이면 1분 안에 알 수 있습니다.
