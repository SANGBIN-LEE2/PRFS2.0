# 🗓️ 01 · 예약하기

예약한 시간에만 렌더를 제출할 수 있습니다. 업로드와 씬 세팅은 아무 때나 해도 됩니다.

> **① 사용 신청** — [신청서 작성하기](https://docs.google.com/forms/d/e/1FAIpQLSfbWrXeXCUe12EwPCIoiAbDmlwUmZwM81xKunAflxbeJOMFSw/viewform)
>
> **② 예약 시트** — [2026_렌더팜 예약시트](https://docs.google.com/spreadsheets/d/1tZ0nRIrGapK0XOyFLU7rCGR2lg47N2PYhEed6g6LB14/edit)
>
> 신청을 먼저 하셔야 합니다. 신청서에 적은 구글 계정으로 예약 시트를 공유해드립니다.

> ✅ **예약 시트에 내 학번이 등록되어 있어야 예약할 수 있습니다.**

## 1-1. 시트 구조

예약 시트는 탭이 여러 개입니다.

```
명단            내 학번과 라이선스 (보기 전용)
10.26~11.01     주차별 예약표
11.02~11.08
   …
사용 규칙        타임블럭·위반 규정
```

**본인이 렌더할 주의 탭**을 고르면 됩니다.

## 1-2. 예약표 보는 법

| 열 | 내용 |
| --- | --- |
| **A — 시간대** | 4시간 단위 타임블럭 |
| **B — 레인** | `pool_a` ~ `pool_d`. **제출할 때 쓰는 값입니다** |
| **C ~ I — 날짜** | 월요일부터 일요일까지 |

한 시간대마다 **4줄**이 있습니다. 실습실 PC를 네 묶음으로 나눠둔 것이라, 같은 시간에 네 팀이 서로 방해 없이 렌더할 수 있습니다.

> 🚫 **회색 칸은 예약할 수 없습니다.** 평일 11:00~19:00 은 수업 시간이라 비워둡니다. 드롭다운도 뜨지 않습니다.

## 1-3. 예약하기

```
1  렌더할 주의 탭을 클릭
2  원하는 날짜 × 시간대 × 레인이 만나는 빈 칸을 클릭
3  오른쪽에 뜨는 ▼ 를 눌러 본인 학번 선택
```

입력하는 게 아니라 **고르는** 겁니다. 등록되지 않은 학번은 아예 들어가지 않습니다.

> 📌 **고른 레인을 꼭 기억하세요.** 제출할 때 Deadline 제출 창의 `Pool` 에 같은 값을 넣어야 합니다. 예약은 `pool_c` 로 해놓고 제출은 `pool_a` 로 하면 예약하지 않은 PC를 쓰게 됩니다. → `05 · 렌더 제출하기`

## 1-4. 예약 취소

```
본인이 예약한 칸을 클릭 → Delete
```

비워집니다. 다른 날짜로 옮길 때도 먼저 지우고 새로 고르세요.

> ⚠️ **남의 예약 칸은 건드리지 마세요.** 누가 어떤 칸을 언제 무엇으로 바꿨는지 전부 기록에 남습니다. (칸 우클릭 → `수정 기록 표시`)

## 1-5. 내가 몇 개 쓸 수 있나

각 주차 시트 **아래쪽 표**에 있습니다.

| 칸 | 뜻 |
| --- | --- |
| **주 최대** | 그 주에 쓸 수 있는 전체 블럭 수 |
| **사용** | 그 주에 이미 예약한 수 — 자동 |
| **남은** | 아직 예약할 수 있는 수 — 자동 |

칸을 고르는 순간 **사용**이 1 늘고 **남은**이 1 줄어듭니다.

> 💡 **주 단위로 초기화됩니다.** 이번 주에 다 썼어도 다음 주 탭에서는 다시 꽉 찬 상태로 시작합니다.

## 1-6. 라이선스

| 프로젝트 분량 | 라이선스 | 주 최대 |
| --- | --- | --- |
| 3분 이하 | 1 | 8 블럭 (32시간) |
| 3 ~ 6분 | 2 | 16 블럭 (64시간) |
| 6분 초과 | 3 | 24 블럭 (96시간) |

라이선스는 **소프트웨어 사용권이 아니라 주당 예약 상한**입니다. 분량이 긴 프로젝트일수록 렌더 시간이 비례해서 늘어나므로 차등 배정합니다.

배정은 졸업준비위원회가 신청 때 받은 분량을 보고 정합니다.

## 1-7. 타임블럭

```
타임블럭 = 4시간

평일   19:00 ~ 익일 11:00    하루 4블럭
주말   24시간                하루 6블럭
```

평일 낮에 비어 있는 것은 실습실 수업 때문입니다.

---

> 🤝 **렌더팜은 공동 자산입니다.** 예약한 시간에만 쓰고, 안 쓰게 되면 미리 지워서 다른 팀이 쓸 수 있게 해주세요. 문제가 생기거나 양보가 필요할 때는 대화로 해결해주세요.

위반 행위와 처리 수위는 `09 · 타임블럭과 사용 규칙` 에 있습니다.
