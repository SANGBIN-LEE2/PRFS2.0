# ⚖️ 09 · 타임블럭과 사용 규칙

---

## 9-1. 타임블럭이란

렌더팜은 공동 장비입니다. 한 팀이 계속 점유하지 않도록 **시간을 블록으로 나눠 예약**합니다.

```
타임블럭 1개 = 4시간
```

| | 사용 가능 시간 | 하루 블럭 |
| --- | --- | --- |
| **평일 (월~금)** | `19:00 ~ 11:00` | 4개 |
| **주말 (토·일)** | 24시간 | 6개 |

평일 낮 `11:00~19:00` 은 수업 시간이라 제외됩니다.

---

## 9-2. 그룹 — 공급량이 4배가 되는 이유

실습실 PC는 **4개 그룹**으로 나뉘어 있고, **한 타임블럭에 4개 팀이 동시에** 렌더할 수 있습니다.

```
평일   5일 × 4블럭 × 4그룹  =  80 블럭
주말   2일 × 6블럭 × 4그룹  =  48 블럭
────────────────────────────────────
주간 총 공급                  128 블럭
```

이 **128블럭**이 한 주 동안 전체 학생이 나눠 쓸 수 있는 양입니다.

---

## 9-3. 라이선스 = 주당 쓸 수 있는 블럭 수

"라이선스"는 **주당 예약 상한**을 뜻하는 단위입니다. 프로그램 라이선스와는 다른 개념입니다.

```
라이선스 1개 = 주 8블럭 = 32시간
```

| 라이선스 | 주 타임블럭 | 주 사용시간 |
| --- | --- | --- |
| 1 | 8 | 32시간 |
| 2 | 16 | 64시간 |
| 3 | 24 | 96시간 |

---

## 9-4. 프로젝트 분량에 따라 배정됩니다

렌더 시간은 영상 길이에 거의 비례합니다. 6분짜리와 2분짜리에게 같은 시간을 주면 6분짜리는 끝내지 못합니다. 그래서 **분량 기준으로 차등 배정**합니다.

| 프로젝트 분량 | 라이선스 | 주 타임블럭 |
| --- | --- | --- |
| 3분 이하 | 1 | 8 |
| 3분 초과 ~ 6분 이하 | 2 | 16 |
| 6분 초과 | 3 | 24 |

> 구체적인 구간은 신청 집계 후 졸업준비위원회가 확정합니다. 전체 라이선스 합계가 **16을 넘으면**(128블럭 초과) 비율을 조정합니다.

### 신청할 때 내는 것

```
팀 프로젝트명
팀장 학번
이메일
프로젝트 분량 (분)
```

**분량은 최종 상영 길이 기준**으로 적어주세요. 렌더해야 할 전체 컷의 길이입니다.

---

## 9-5. 상한선이지 할당량이 아닙니다

라이선스는 **"여기까지 예약할 수 있다"** 는 뜻이지, 그만큼이 확보된다는 뜻이 아닙니다.

블록은 **선착순**입니다. 늦게 예약하면 원하는 시간대가 없을 수 있습니다.

> **심야 블록(`23:00-03:00`, `03:00-07:00`)이 가장 한가합니다.** 렌더는 사람이 지켜보지 않아도 되니, 저녁에 제출해두고 자는 방식을 권합니다.

---

## 9-6. 지켜야 할 것

| | |
| --- | --- |
| 🕐 | **예약한 시간에만** 사용 — 예약 시간 외 Worker PC 로그인 금지 |
| 🎯 | 제출 시 **예약한 그룹**과 똑같이 지정 |
| 📁 | 모든 파일은 **NAS에**, 경로는 **영문·숫자**로 |
| 🧪 | 전체 렌더 전에 **3프레임 테스트** |
| 🧹 | 끝나면 **결과물 가져가고 폴더 비우기** |
| 🔌 | 실습실 PC를 **임의로 끄지 않기** |
| 🙅 | 남의 예약·폴더·결과물 건드리지 않기 |
| 💬 | 문제 생기면 **혼자 붙들지 말고 연락** |

---

## 9-7. 위반 시

아래 행위는 시트 수정 기록에 남으며, 누적 시 사용 제한 또는 타임블럭 삭감이 적용됩니다.

| 위반 유형 | 설명 |
| --- | --- |
| 타 학번으로 예약 | 본인 팀이 아닌 학번으로 블럭 선점 |
| 타인의 예약 수정·가로채기 | 이미 예약된 칸을 변경하거나 삭제 |
| 예약 없이 렌더 제출 | 예약하지 않은 시간·그룹에 제출 |
| 고의적 리소스 소모 | 불필요한 예약·취소 반복, 쓰지 않을 블록 선점 후 방치 |

| 적발 횟수 | 처리 |
| --- | --- |
| 1회 | 경고 및 기록 공유 |
| 2회 | 해당 주 라이선스 −2블럭 |
| 3회 | 3일간 렌더팜 사용 정지 |
| 4회 이상 | 팀 렌더팜 사용권 박탈 (졸준위·지도교수 협의) |

## 🤝 부탁

렌더팜은 공동 자산이며, 모두의 졸업 프로젝트 완성을 위해 운영됩니다.

이 규칙은 공평한 제작 환경을 유지하기 위한 **최소한의 기준**입니다. 정직하게 사용해주시고, 문제가 생기거나 양보가 필요할 때는 항상 대화로 해결해주세요.
