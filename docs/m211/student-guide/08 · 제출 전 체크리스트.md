# ✅ 08 · 제출 전 체크리스트

제출할 때마다 한 번씩 훑어보세요. 1분이면 됩니다.

---

## 공통

```
□  예약 시트에 내 학번을 넣었다
□  프로젝트 폴더를 통째로 NAS에 올렸다 (씬 파일만 X)
□  폴더·파일 이름에 한글·공백·점(.)이 없다
□  output 폴더를 미리 만들어뒀다
□  Ctrl+S 로 저장했다
□  Pool 을 예약한 레인과 똑같이 골랐다
□  Camera 를 골랐다 (persp 아님)
□  먼저 1-3 프레임으로 테스트했다
```

---

## 🅰 마야

```
□  레퍼런스를 Import 로 바꿨다
□  File Path Editor 에 빨간 줄이 0개다
□  (권장) File name prefix 를 NAS output 경로로 넣었다
□  Render Device 를 CPU 로 바꿨다
□  File → Set Project 를 작업 폴더로 지정했다
```

---

## 🅱 블렌더

```
□  실습실 설치 버전 이하로 저장했다
□  Pack Resources 를 했다
□  Report Missing Files 에서 누락이 없다
□  출력 경로가 \\ 로 시작한다  ( // 아님 )
□  출력 경로 끝에 #### 를 붙였다
□  Device 를 CPU 로 바꿨다
□  Submit Blender Scene File With The Job 은 체크 안 했다
```

---

## 렌더가 끝난 뒤

```
□  결과물 장수가 프레임 수와 맞는지 세어봤다
□  결과물을 내 저장장치로 옮겼다
□  NAS output 폴더를 비웠다
□  다 쓴 input 폴더도 비웠다
```
