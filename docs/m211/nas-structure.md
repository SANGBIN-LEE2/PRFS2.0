# M211 NAS 디렉토리 구조

학생이 직접 파일을 올리고 결과물을 받아가는 작업 영역이다.

```
\\223.194.101.83\2026_renderfarm\
```

---

## 설계 원칙

**Repository 볼륨과 분리한다.** 학생 작업 영역을 Deadline Repository가 있는 볼륨에 두면, 렌더 결과물(특히 EXR 시퀀스)이 볼륨을 채워 팜 전체가 멈춘다. 별도 볼륨에 공유 폴더를 만들어 구조적으로 차단했다.

**학번/날짜로 나눈다.** 누가 언제 무엇을 돌렸는지 경로만 보고 알 수 있어야 한다. 정리와 용량 관리도 이 단위로 한다.

**경로에 한글과 공백을 쓰지 않는다.** Worker가 경로를 문자열로 처리하므로 렌더 실패의 흔한 원인이 된다.

**학번 폴더는 관리자가 미리 만든다.** 학생이 직접 만들면 오타가 나고, 그러면 예약 시트의 학번과 폴더가 어긋나 추적이 불가능해진다. 신청이 접수된 학번만 폴더를 만들어두면 접근 통제 역할도 겸한다.

**프로젝트 내부 구조는 강제하지 않는다.** Deadline은 폴더 이름을 해석하지 않으므로 `scenes/textures/cache` 같은 틀을 요구할 이유가 없다. 오히려 마야 기본 프로젝트(`sourceimages`)와 충돌해 학생이 자기 프로젝트를 재배치하게 만든다. 쓰던 구조 그대로 통째로 올리게 하는 편이 실패가 적고, `File → Set Project` 도 그대로 동작한다.

## 전체 구조

```
2026_renderfarm/
├── 00_READ_ME_FIRST/            학생 안내문
│   ├── 00_학생공지문.txt
│   ├── 01_렌더팜_사용안내.txt
│   ├── 02_폴더구조_규칙.txt
│   ├── 03_자주발생하는문제.txt
│   └── 04_렌더팜_사용법_4p.pdf
│
├── input/                       업로드
│   └── <학번>/                  ← 관리자가 신청 학번으로 미리 생성
│       └── <YYYYMMDD>_<작업명>/ ← 학생이 생성
│           └── <프로젝트 폴더>/  ← 쓰던 구조 그대로
│
├── output/                      결과물
│   └── <학번>/                  ← 관리자가 미리 생성
│       └── <YYYYMMDD>_<작업명>/ ← 학생이 생성
│
└── _admin/                      관리자 전용
    ├── scripts/
    ├── docs/
    └── logs/
```

## 작업 폴더 이름 규칙

```
형식 :  <YYYYMMDD>_<작업명>
예시 :  20261020_test
        20261101_final
```

- 날짜 8자리
- 영문 소문자 + 숫자 + 밑줄만
- 한글·공백·특수문자 금지

## 경로 사용 규칙

**마야 안의 모든 경로는 UNC로 넣는다.** 매핑된 드라이브(`Z:\`)는 쓰지 않는다 — Worker PC에는 그 드라이브가 없다.

| 설정 | 값 |
| --- | --- |
| Project Path | `\\223.194.101.83\2026_renderfarm\input\<학번>\<작업폴더>` |
| File name prefix | `//223.194.101.83/2026_renderfarm/output/<학번>/<작업폴더>/<이름>` |
| 텍스처 | `\\223.194.101.83\2026_renderfarm\input\<학번>\<작업폴더>\textures\...` |

탐색기 탐색용으로 네트워크 드라이브를 연결하는 것은 무방하나, 씬에 저장되는 경로는 반드시 UNC여야 한다.

## 권한

| 계정 | 권한 |
| --- | --- |
| 학생 계정 | `input`, `output` 읽기/쓰기 |
| `deadline_svc` | 전체 읽기/쓰기 (Worker가 씬을 읽고 결과를 씀) |
| 관리자 | 전체 |

`_admin`은 학생 접근에서 제외한다.

---

## 운영 규칙

**결과물은 받아간 뒤 폴더를 비운다.** EXR 시퀀스는 용량이 커서 방치하면 다른 학생이 렌더를 못 한다. 안내문과 매뉴얼 양쪽에 명시했다.
